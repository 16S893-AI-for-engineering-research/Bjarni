14 Sept 2026 · Site scaffold, D3 visuals, easter eggs, GitHub Pages

Delegated Built the full four-page static site (index, project, about, secret) end-to-end from a plain-language spec: shared nav/footer injection, scroll-reveal animation, cursor-reactive parallax background, and D3.js visuals — a fuel energy-density scatter plot, a config × size status matrix (tube-and-wing / D8 / BWB / truss-braced wing across regional to ultra-widebody), and an animated "today → target" expansion-rings diagram.

Checked Fuel cost and life-cycle-assessment figures were not invented — pulled directly from an existing MATLAB research script (Energy_Carrier_Impact.m) with real, dated literature sources per fuel, then normalized to a common $/MJ and gCO2e/MJ basis so all 13 fuels are comparable on equal footing. Aircraft photography (tube-and-wing, D8, BWB, truss-braced wing) was sourced from Wikimedia Commons / NASA public-domain archives rather than AI-generated, with credit lines placed under each photo.

Checked Verified every layout and interaction pass with headless-Chrome screenshots and DOM dumps before calling it done — confirmed exact SVG element counts (matrix cells, scatter points, timeline entries), checked for zero console errors across all pages, and cross-browser hardened the Konami-code listener (Safari's inconsistent key/keyCode handling) after an initial report that it silently failed there.

Rejected / open First pass at the Blended Wing Body and D8 hero silhouettes didn't read clearly as aircraft — flagged and redrawn twice before landing on shapes that were unambiguous at a glance. The relative tank mass/volume penalty chart was cut entirely on request rather than kept as dead weight once it stopped adding to the story.

Verification path: headless-Chrome screenshots and DOM element counts after every visual change; node --check on every JS file before commit; manual cross-reference of fuel cost/LCA numbers against the source MATLAB script rather than trusting memory of typical values. Not yet verified: no automated cross-browser test suite beyond manual Safari-focused Konami-code fixes; no accessibility (screen reader) pass yet.
